# 正修科技大學 3D 模擬校園導覽與安全系統 (Cheng Shiu University 3D Virtual Campus)

[![GitHub Pages](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-brightgreen?style=for-the-badge&logo=github)](https://tsai-py.github.io/csu-campus-tour/)

🔗 **線上正式體驗網址**：[https://tsai-py.github.io/csu-campus-tour/](https://tsai-py.github.io/csu-campus-tour/)

嚴格依據最新官方**「正修科技大學校園安全地圖」**重新校準與重構之 **3D 擬真校園模型、第一人稱貼地漫步與智慧導覽系統**。

---

## 🌟 核心特色功能

### 🚶 1. 全新：校園第一人稱貼地行走模式 (Ground Walking Mode)
- **貼地視角體驗**：視線高度固定於離地面 **1.8 公尺**（真人視線高度），如同親身漫步於正修校園步道與林蔭大道！
- **流暢多重操作支援**：
  - **鍵盤操控**：`W` / `↑` 前進，`S` / `↓` 後退，`A` / `D` 平移，`←` / `→` 轉向，`Shift` 切換跑步。
  - **滑鼠環視**：按住滑鼠左鍵拖曳，可自由 360 度環顧四周建築與天際線。
  - **螢幕虛擬方向鍵 (Virtual D-Pad)**：畫面提供 ▲ ▼ ◀ ▶ 螢幕觸控按鈕，方便觸控板或行動裝置行走。
- **擬真步伐起伏 (Head Bobbing)**：漫步時帶有微幅自然的人類行走起伏節奏。
- **🐾 自動貼地導覽散步 (Auto Path Stroll)**：一鍵開啟自動漫遊，系統會依序沿著校園實體步道自動前進與轉彎，漫遊全校重點景點。
- **快捷出發點**：隨時一鍵傳送至「學校正門」、「綜合大樓」、「人文大樓 7-11」、「圖書科技大樓」、「籃網球場」、「宿舍天橋」。

### 🗺️ 2. 嚴格對照「校園安全地圖」拓撲佈局
- **澄清路（橫向主幹道）**：置於校區正下方，**❶ 學校正門** 牌樓座落於中央迎賓中軸線，左右兩側完整配置 **❷ AB棟大型智慧停車場**。
- **大埤路（縱向西側幹道）**：位於校園左側，向北通往澄清湖風景區。
- **正修路（斜向貫穿幹道）**：斜貫校園中樞，北側為長庚醫院停車場，中段設有 **㉕ 學校側門（含警衛室與車輛道閘）**，北端設有跨街立體天橋。
- **⓴ 天橋與 ⓳ 正修宿舍**：完整建模跨越正修路的**行人景觀安全天橋**，保護學子安全人車分流，直通上方的「**文山學園**」與「**正義學舍**」學生宿舍社區。
- **中央內部停車場 [P]**：精準座落於 **❿ 工管館**、**㉗ 生活創意大樓** 與 **㉙ 產學共榮大樓** 之間的合圍廣場。

### 🏢 3. 重構各棟建築外觀、色彩與機能特色（完整對照編號 1 至 29）
- **❸ 綜合大樓**：粉紫色長型行政中樞大樓，前方設有迎賓大階梯與聯合服務大廳。
- **❹ 體育室**：藍色多功能室內體育館，外圍環繞標準**紅色 PU 田徑跑道與內場綠地**。
- **❾ 學生活動中心**：暖橘色現代折線建築，1 樓為學生餐廳美食廣場，2 樓特設「**✚ 2F 健康中心**」與 AED 醫療站。
- **⓫ 人文大樓**：醒目的亮黃色圓弧花瓣造型大樓，1 樓設有 **7-ELEVEN 正修門市** 與地下機車停車場。
- **⓯ 圖書科技大樓**：校區中心最醒目的紫色 12 層超高地標，十字流線側翼、避雷天線塔與科技帷幕玻璃。
- **⓰ 電機館、⓱ 南校區教學大樓、⓲ 管理學院大樓**：依地圖順著東北斜坡延伸排布。
- **㉒ 幼兒保育館**：沿正修路舒展之長條橙色建築，並標示全校「**🛡️ 校安中心 (S標章)**」24小時安全守護中樞。
- **㉑ 籃球場、網球場**：位於 22 幼保館北側、25 側門對面，具備標準雙色防滑鋪面與夜間照明。
- **㉓ 超微量實驗室**：國家級 TAF 認證之頂尖分析中心，位於體育館北側。
- **㉗ 生活創意大樓**：南側藍色多翼旗艦大樓，具備現代幾何立體造型與挑高展演中庭。

### 🚨 4. 校園安全與急救網絡完整視覺化
- **10 處 AED 站標記**：在 3, 4, 7, 9, 11, 15, 17, 18, 19, 22, 27, 29 棟大樓醒目標示「♥ AED」紅心急救徽章。
- **13 處戶外緊急求助鈴柱 (Emergency Bells)**：全校重要路口設立紅色求助鈴柱，配備**夜間紅色警示呼吸信號燈**。
- **夜間加強照明走廊 (金黃色發光動線)**：切換至「🌙 夜景」模式時，地表加強照明路線將綻放清晰的金黃色導引光芒！

## 🚀 啟動方式

直接執行：
`c:\download\csu-campus-tour\start_server.bat`
或在命令列執行：
```bash
cd c:\download\csu-campus-tour
python -m http.server 8088
```
瀏覽器前往：`http://localhost:8088/index.html`
